🧠 Respuestas Conceptuales
Fundamentos teóricos aplicados en la arquitectura del proyecto

1. ¿Por qué hashear contraseñas?

El almacenamiento de contraseñas en texto plano representa una de las vulnerabilidades más graves de seguridad. Si la base de datos resulta comprometida por una filtración o ataque, todas las credenciales de los usuarios quedarían expuestas instantáneamente.

  • Irreversibilidad: Las funciones hash unidireccionales (como scrypt o pbkdf2) transforman la contraseña en una cadena de caracteres fija de la cual no se puede recuperar el texto original.
  • Salt Integrado: Previenen ataques de diccionario y tablas arcoíris (Rainbow Tables) al incluir sal aleatoria en cada hash.
  • Protección del usuario: En la API, el servidor únicamente compara el hash generado en el login contra el hash almacenado, manteniendo el secreto intacto.

2. Ventajas de usar SQLite en este proyecto

SQLite es un motor de base de datos relacional ligero, autónomo y sin servidor (serverless), ideal para el ámbito del PFO 2:

  • Cero Configuración: No requiere la instalación ni administración de un servicio de base de datos externo (como PostgreSQL o MySQL).
  • Persistencia de Archivo Único: Toda la base de datos reside en el archivo database/tareas.db, garantizando portabilidad directa.
  • Rendimiento & ACIDs completos: Cumple plenamente las propiedades ACID y ofrece respuestas ultrarrápidas para aplicaciones de consumo directo o prototipado API.
  • Integración Nativa: Incluido por defecto en la biblioteca estándar de Python (import sqlite3).

🚀 Instrucciones para Ejecutar el Proyecto
Pasos para desplegar el servidor, cliente y ejecutar tests

1. Clonar el repositorio e instalar dependencias

git clone https://github.com/tu-usuario/api-rest-python.git cd api-rest-python # Crear entorno virtual y activarlo python -m venv .venv source .venv/bin/activate # En Linux/Mac .venv\Scripts\activate # En Windows # Instalar dependencias pip install -r requirements.txt

2. Iniciar el Servidor Flask

python servidor.py

3. Ejecutar el Cliente en Consola (en otra terminal)

python client/cliente.py

4. Ejecutar el suite de pruebas automatizadas

pytest -v
